### 📝 Overview
A professional demonstration of a **Gasless Smart Wallet** on Solana. Focused on removing onboarding friction using the Lazorkit SDK philosophy.

### ✨ Key Features
- **Passkey Login:** Seedless onboarding (no seed phrases needed).
- **Gasless Transactions:** Send & Swap functionality with **$0 Gas Fees** (sponsored by Paymaster).
- **Live Charts:** Real-time SOL/USDT price tracking via TradingView.
- **Mobile UI:** Clean, responsive interface built with Tailwind CSS.

### 🛠️ Tech Stack
- HTML5, Tailwind CSS, JavaScript, Vercel.
